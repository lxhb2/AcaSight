# Sci-XRD 高级算法使用指南

## 概述

Sci-XRD 平台现已集成10种高级XRD分析算法，可通过"高级算法"按钮访问。

## 算法列表

### 1. K-alpha2剥离 (K-alpha2 Stripping)
**用途**: 去除Cu靶X射线中K-alpha2辐射的贡献

**原理**: 使用Rachinger方法，根据K-alpha1和K-alpha2的波长差异，从图谱中减去K-alpha2的贡献。

**参数**:
- 波长Ka1: 1.5406 Å
- 波长Ka2: 1.5444 Å
- 强度比: 0.5

**输出**: K-alpha2剥离后的图谱

---

### 2. 高斯峰形拟合 (Gaussian Fit)
**用途**: 使用高斯函数拟合衍射峰

**函数形式**: `y = A * exp(-(x-μ)²/(2σ²))`

**输出参数**:
- 峰位 (center)
- 振幅 (amplitude)
- FWHM (半高宽)
- Sigma (标准差)

---

### 3. 洛伦兹峰形拟合 (Lorentzian Fit)
**用途**: 使用洛伦兹函数拟合衍射峰

**函数形式**: `y = A / (1 + ((x-μ)/γ)²)`

**输出参数**:
- 峰位 (center)
- 振幅 (amplitude)
- FWHM (半高宽)
- Gamma (形状参数)

---

### 4. 伪Voigt峰形拟合 (Pseudo-Voigt Fit)
**用途**: 使用混合高斯-洛伦兹函数拟合衍射峰

**函数形式**: `y = A * [η * L(x) + (1-η) * G(x)]`

**输出参数**:
- 峰位 (center)
- 振幅 (amplitude)
- FWHM (半高宽)
- Eta (混合参数，0=纯高斯，1=纯洛伦兹)

---

### 5. 计算d值 (Calculate d-spacing)
**用途**: 根据2θ角度计算晶面间距

**公式**: `d = λ / (2 * sin(θ))`

**参数**:
- 波长: 1.5406 Å (Cu K-alpha)

**输出**: d值 (Å)

---

### 6. 计算FWHM (Calculate FWHM)
**用途**: 计算峰的半高宽

**方法**: 在峰的半高处测量宽度

**输出**: FWHM (度)

---

### 7. 晶格参数计算 (Lattice Parameter)
**用途**: 计算立方晶系的晶格常数

**公式**: `a = d * √(h²+k²+l²)`

**支持晶系**: 立方晶系

**输出**:
- 晶格常数 a
- 标准偏差

---

### 8. 应变/应力分析 (Strain/Stress Analysis)
**用途**: 根据峰位移计算微观应变

**公式**: `应变 = Δd / d`

**参数**:
- 泊松比: 0.3
- 杨氏模量: 200 GPa

**输出**:
- 平均应变
- 估计应力 (MPa)

---

### 9. 定量相分析 (Quantitative Analysis)
**用途**: 使用RIR方法计算各相的重量百分比

**方法**: Reference Intensity Ratio (RIR)

**公式**: `Wt% = (I/RIR) / Σ(I/RIR) * 100%`

**输出**: 各相的重量百分比

---

### 10. 图谱相似度计算 (Pattern Similarity)
**用途**: 比较两个XRD图谱的相似度

**方法**: Pearson相关系数

**输出**: 相似度 (-1到1，1表示完全相同)

---

## 使用步骤

1. **加载数据**: 点击"打开文件"加载XRD数据
2. **选择算法**: 点击"高级算法"按钮
3. **配置参数**: 在对话框中查看算法参数
4. **运行算法**: 点击"运行算法"按钮
5. **查看结果**: 结果将显示在文本框中

## 注意事项

1. **峰形拟合**: 需要scipy库支持，如果未安装会提示错误
2. **K-alpha2剥离**: 仅适用于Cu靶X射线数据
3. **晶格参数**: 目前仅支持立方晶系
4. **定量分析**: 需要已知各相的RIR值

## 示例

### 示例1: 计算石英(101)面的d值
- 2θ = 26.6°
- 计算结果: d = 3.348 Å

### 示例2: 高斯拟合
- 峰位: 25.0°
- FWHM: 0.5°
- 拟合结果将给出精确的峰参数

### 示例3: 晶格参数计算
- 输入: 硅的三个峰 (111), (220), (311)
- 输出: a = 5.431 Å

## 故障排除

| 问题 | 解决方案 |
|-----|---------|
| "未检测到峰" | 调整峰检测参数或检查数据质量 |
| "拟合失败" | 检查scipy是否安装: `pip install scipy` |
| "算法执行失败" | 查看错误信息，检查输入数据格式 |

## 技术参考

### 相关公式

1. **布拉格定律**: nλ = 2d sin(θ)
2. **谢乐公式**: D = Kλ / (B cos(θ))
3. **应变公式**: ε = Δd / d = -cot(θ) Δθ
