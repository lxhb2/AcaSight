## 十五、开发约束与原则

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         开发约束与原则                                    │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │  原则一：复用优先，禁止造轮子                                       │  │
│  │  · Agent调度: 复用LangChain/LlamaIndex，不自建调度框架              │  │
│  │  · RAG引擎: 复用RAGFlow(Docker)，不自建文档解析                     │  │
│  │  · 格式引擎: 复用Pandoc+citeproc，不自建格式转换                    │  │
│  │  · 编辑器: 复用Milkdown，不自建富文本编辑器                         │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │  原则二：渐进式开发，每步可验证                                      │  │
│  │  · 每个方向的每个阶段独立可测试                                      │  │
│  │  · 新旧功能并行运行，逐步切换                                        │  │
│  │  · 单个章节开发完毕立即复盘，等待用户验收                            │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │  原则三：效率优先，杜绝冗余流程                                      │  │
│  │  · 网络文献: 检索即用，不强制先存储后调用                            │  │
│  │  · AI拆分: 按需触发，未使用文献不拆分                                │  │
│  │  · 临时数据: 定时清理，不占用持久化资源                              │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │  原则四：用户可控，强化人机协同                                      │  │
│  │  · 数据/插图使用核心环节必须保留用户自主选择权                       │  │
│  │  · 大纲必须经用户审阅修订后才进入正文撰写                            │  │
│  │  · AI推荐但用户决策，AI执行但用户确认                                │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │  原则五：数据规范，全场景适配                                        │  │
│  │  · 结构化数据统一存储标准，适配知识图谱+写作调用+导出归档            │  │
│  │  · 素材文件分类归档，保留原始格式，支持重复调用                      │  │
│  │  · 绘图过程数据单独保存，支持二次修改和重新生成                      │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │  原则六：循环迭代，反馈驱动                                          │  │
│  │  · 梳理→研判→替代→定稿→开发→复盘→反馈→回到梳理                     │  │
│  │  · 结合反馈意见调整优化，持续迭代                                    │  │
│  │  · 技术手册与架构图随迭代同步更新                                    │  │
│  └────────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────┘
```
