3.1 获取所有文件名

绝对路径与相对路径

要想打开文件，首先要知道文件的位置。众所周知，文件是通过文件路径定位的，在Python中，路径可以用字符串来表示。

而路径又分为绝对路径和相对路径。

绝对路径就是文件或文件夹在硬盘上的完整路径。永远都是根目录开头，具体的文件或文件夹名称做结尾。

在Windows系统中，绝对路径的开头永远是磁盘的名称，比如C:或者D:。而在Mac系统中，绝对路径会使用/作为开头。

举例说明一下：

Windows系统中，C盘根目录中有个名为【codes】的文件夹，该文件夹内有【工作文件夹】和【oa01.py】，【工作文件夹】中有txt文件【0520_2020会议记录.txt】。

用绝对路径表示这几个文件夹和文件：

# 文件'oa_01.py'的绝对路径

# 文件'05_20_2020会议记录.txt'的绝对路径
'C:/codes/工作文件夹/05_20_2020会议记录.txt'

同理，Mac系统，根目录中有名为【codes】的文件夹，该文件夹内有【工作文件夹】和【oa01.py】，【工作文件夹】中有txt文件【0520_2020会议记录.txt】。

打开文件需要使用Python内置函数open()

如上所示，open()函数用于打开一个文件，创建一个 file 对象（即文件对象）。

这样，才能在后面调用文件对象的相关方法进行读写。

上图是Python官方文档中有关open()函数的部分。

别看参数这么多，今天我们只需要用到其中的三个：file、mode和encoding。

第一个参数 file：表示我们要打开的文件的路径，这里可以传入我们刚才学过的相对路径。当然，传入绝对路径也是可以的，在现实使用中，你可以根据实际情况自行选择。

第二个参数 mode：决定了打开文件的模式，最主要的模式有：只读（r），写（w），追加（a）等。mode可取的值见如下表格。

【温馨提示】下面表格的内容你完全不需要去记忆，只需要了解即可，等你遇到问题时，可以根据具体的问题来选择使用下面的模式。

加载中...

点击重新加载

这个参数很有意思，值得注意。

1.参数mode并不是强制的，它有个默认值'r'。也就是说，打开文件时，默认只读模式。

  1. 当mode='w'，即写模式时，open()函数会打开一个文件只用于写入，如果该文件已存在则打开文件，并从开头开始编辑，即原有内容会被清空。如果该文件不存在，创建新文件。

  1. 当mode='a'，即追加模式时，open()函数会打开文件用于追加。如果该文件已存在，新的内容将会被写入到已有内容之后。如果该文件不存在，创建新文件进行写入。

第三个参数 encoding：闪光科技金融公司内部txt文件的编码方式一般是utf-8，为了避免错误，需要把encoding设置为'utf-8'，即写为encoding='utf-8'。

当你在本地写代码时，需要根据不同的系统来配置这个参数，Windows下配置为utf-8-sig，MacOS下配置为utf-8。

4.3 读取文件内容

使用open()函数打开文件后，我们就获得了一个文件对象。

要想读取文件里的内容，除了需要将open()函数的参数mode设置为'r'以外，还需要使用文件对象的方法read()。

该方法的作用是读取文件对象中的所有数据并返回，返回值的类型是字符串。具体的写法是文件对象.read()

读取文件内容后，再使用print()函数打印出返回的字符串。这样就可以读取并查看txt文件中的内容了。

4.4 关闭文件

“读取文件”的最后一步是，关闭文件对象。

写法是文件对象.close()。我希望你牢牢记住，每一个打开的文件对象，都应该被关闭。

如果文件对象没有被关闭，那么程序在执行的过程中就会一直占用系统资源。这就像冰箱门打开以后不关闭，就会增大耗电量；浏览器上不关掉未查看的网页，就会一直占用系统内存一样。

# 目标文件是工作文件夹内的06_01_2020会议记录.txt文件
target_file = './工作文件夹/06_01_2020会议记录.txt'
# 需要添加的内容列表
content_list = ["会议记录：陈知枫", "会议复盘：徐小刚", "会议室清洁：廖雨"]
# 使用 open() 函数打开 06_01_2020会议记录.txt 文本文件，并使用追加模式'a'，记得将编码设置为'utf-8'
file = open(target_file, 'a', encoding='utf-8')
# 使用for循环遍历内容列表
for content in content_list:
    # 使用方法，文件对象.write()
    file.write(content)
# 关闭文件对象
file.close()

# 目标文件是工作文件夹内的06_01_2020会议记录.txt文件
target_file = './工作文件夹/06_01_2020会议记录.txt'

5.3 功能块总结

总结一下，判断关键词并写入功能块的内容：

1.文件写入需要使用文件对象.write()，该方法可以将字符串写入文件对象。

2.open()函数的参数mode应该传入'w'或'a'。'w'是从头开始写，会删除掉文档内原有的内容；'a'是在结尾处写入，不会删除文档原有的内容。如果文件不存在，'w'和'a'都会创建新的文件。

6.2 知识归纳与总结

今天我们复习了方法os.listdir()，该方法可以获取目标文件夹里所有文件和文件夹的名称。

然后我们重点学习了如何用Python进行文件读写。

内置函数open()，可以用来打开一个文件并返回一个文件对象。

该函数有三个重要的参数：

1.参数file，要打开文件的路径（相对路径或绝对路径）

2.参数mode，我们可以根据需要，选择读模式'r'，写模式'w'或追加模式'a'。

3.参数encoding，编码，设置为'utf-8'即可。

得到文件对象后，可以使用文件对象的方法read()，该方法会将文件内容以字符串形式返回。

将文本内容写入文件对象，可以使用方法write()，该方法需要将open()函数的参数mode设置为写模式w或者追加模式a。

所有被打开的文件，最后都应该被关闭。可以使用文件对象的方法close()。
