3.1 打开工作表

既然我们之前已经复习过了如何打开一个工作簿和工作表，那就直接进入。如何打开文件夹下所有工作簿？

“各部门利润表汇总”文件夹中的52个工作簿——“事业01部.xlsx”、“事业02部.xlsx”等等，每次打开都要重复告诉load_workbook()函数它们的不同路径。

而工作簿的路径又有很强的规律性，都是文件夹路径 + 文件名。

那如果我们能用循环遍历取到不同的文件名，再一一拼接上前面的文件夹路径，问题就不大了。所以需要用到os.listdir()和for循环。

接下来，请你体验下面这个代码，看一看终端打印的路径。

获取所有文件路径

有了循环获取的路径，就可以去实现第一个功能块——打开工作表啦。正确代码是这样的：

# 导入模块
import os
# 设置文件夹路径
path = './各部门利润表汇总/'
# 返回当前目录下所有文件名
files = os.listdir(path)
# 循环文件名列表
for file in files:
    # 拼接文件路径
    file_path = path + file
    # 打开工作簿
    wb = load_workbook(file_path)
    # 打开工作表
    ws = wb.active

Sheet.max_row的功能

有了Sheet.max_row得到最后一行的行号，不管是只有3行的工作表，还是有20多行的工作表，我们都可以轻松确定出“表中”这个范围结束的行号。看下面这个题目，可能会对你有启发：

单选题

思考：对于各种不同的工作表ws，其“表中的数据范围”，表示方法正确的是哪个选项：

A.

ws.iter_rows(min_row = 2, max_row = 9)

B.

ws.iter_rows(min_row = 2, max_row = ws.max_row)

C.

ws.iter_rows(min_row = 2, max_row = ws.max_row - 1)

回答错误
答案是 C

C选项中将ws.max_row减1正确，可以得到“倒数第二行”的行号。

上题中，A选项不正确，因为前提条件是对于各种不同的工作表，A选项只能取出有10行数据的工作表的表中区域。
B选项中，如果将iterrows()的最大行参数设置为ws.maxrow，就会取到最后一行，即表尾那一行。因此表中的数据范围是从第2行到ws.max_row - 1行。

有了“表中”的数据范围，我们就可以循环取出其中每一行了：

# 取出“表中”的各行，并打印
for row in ws.iter_rows(min_row=2, max_row = ws.max_row - 1):
    print(row)

但是我们要想调整“表中”的单元格样式，还需要能够取到每一个单元格。这里我们需要用到for循环的嵌套：

for row in ws.iter_rows(min_row=2, max_row = ws.max_row - 1):
    for cell in row:
        print(cell)

在上一段代码for循环读取“表中”每一行的基础上，循环体中增加一个for循环，去遍历这一行row中的单元格cell。这样就能用for循环的嵌套，来取出“表中”的所有单元格了。

假设有一个工作簿wb，文件存储在原路径“file_path”变量中，如果使用openpyxl库保存该工作簿，以下哪条代码是正确的？

A.

wb.save(file_path)

B.

openpyxl.save(wb)

C.

save wb as file_path

回答错误
答案是 A

正确的语法是：wb.save(文件路径) ，功能是将wb工作簿保存在对应的路径下。

当“保存工作簿”放在①号位置，执行顺序是：打开一个工作簿，取出活动工作表，对样式进行修改，然后保存工作簿。接下来回到for循环的开始，打开下一个工作簿，然后重复以上操作。直到取出文件名列表中最后一个工作簿，取出工作表，修改样式并保存工作簿。

当“保存工作簿”放在②号位置，执行顺序是：打开工作簿，取出工作表，进行样式修改。回到for循环的开始，打开下一个工作簿，重复以上操作。直到取出最后一个工作簿、工作表，进行样式的修改。遍历完文件名列表，for循环结束。执行循环外的语句——保存最后一个wb工作簿。

👀看出来了吗？如果放在②号位置就只会保存对最后一个工作簿的修改哦。因此我们的功能块五确定应该放在功能块一中for循环的内部。

还有一个变化: 2.导入模块的语句都放到了程序最开头，然后功能块三也放到功能一之前。

功能块三定义样式的语句不需要放在功能块一的for循环下，否则程序每次循环就会重复去定义相同的单元格样式，这是没有必要的。所以就将这一块代码前置，而功能分块依旧清晰。
