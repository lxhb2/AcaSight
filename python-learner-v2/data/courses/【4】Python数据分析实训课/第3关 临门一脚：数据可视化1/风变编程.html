3. 数据可视化

3.1 可视化概念

我先带你详细了解一下数据可视化的概念。

数据可视化也称为数据展现，它可以利用人对形状、颜色的感官敏感，有效地传递信息，帮助用户更直观的从数据中发现关系、规律、趋势。

数据可视化可以将枯燥的数据变得生动，就拿我们上节课得出的一个结论来说：

我们在针对本(专)科群体设计广告文案时，可以以价廉物美为主题，因为有60%的本(专)科学生都是因为价格便宜才来购买我们公司的书籍。

并且在本(专)科学生的购买原因这列数据中，价格便宜的占比是排名第二的书籍绝版这个原因的6倍，非常的明显，也适合我们去做广告的精细投放。

如果只是干巴巴的看这两句话，一般人很难直观地感受到本(专)科学生的购买原因中，价格便宜的压倒性比例。

但假如我们换一种形式，给本科生的购买原因配上一张饼图：
