5.3 Series对象和DataFrame对象的区别与联系

首先我们来讲解一下它们的区别。虽然Series对象和DataFrame对象都是由索引和数据所构成的，但是他们的索引方式是不一样的。

Series对象只包含有一组索引，而DataFrame包含有两组索引。具体效果如下图所示：

加载中...

点击重新加载

Series和DataFrame对象的行索引默认都是0, 1, 2, 3,…。只不过，DataFrame对象会比Series对象多一个列索引。

我们在观察刚才图片展示的结果时，会发现，Series对象只包含了一组数据和索引。

如果没有特地说明这组数据代表的是用户年龄，那我们是很难了解到这个信息的。
