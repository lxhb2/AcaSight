## 🔒 安全机制

借鉴 OpenClaw 和 HermesAgent 的设计：

### 1. 路径边界检查
- 使用 `os.path.normpath(os.path.abspath())` 统一处理 Windows 短/长路径名
- 防止 `../` 路径遍历攻击

### 2. 敏感路径黑名单
```python
WRITE_DENIED_PATHS = {
    ~/.ssh/authorized_keys, ~/.ssh/id_rsa, ~/.ssh/id_ed25519,
    ~/.ssh/config, ~/.bashrc, ~/.zshrc, ~/.netrc, ~/.pgpass,
    /etc/sudoers, /etc/passwd, /etc/shadow, ...
}

WRITE_DENIED_PREFIXES = [
    ~/.ssh/, ~/.aws/, ~/.gnupg/, ~/.kube/, /etc/sudoers.d/, ...
]
```

### 3. 设备路径黑名单
```python
BLOCKED_DEVICE_PATHS = {
    "/dev/zero", "/dev/random", "/dev/urandom",  # 无限输出
    "/dev/stdin", "/dev/tty", "/dev/console",    # 阻塞等待输入
}
```

### 4. 符号链接检测
- 读取时检测并报告符号链接
- 防止 symlink 攻击

### 5. 大小限制
- 默认最大读取: 100K 字符 (≈ 25-35K tokens)
- 默认最大写入: 10 MB

## 🔧 API

### 主要函数

```python
from utils.safe_file_ops import safe_read_file, safe_write_file, safe_delete_file

# 读取文件
result = safe_read_file(
    filepath="/path/to/file.txt",
    workspace_root="/path/to/workspace",
    max_chars=100_000,
    offset=0,  # 起始行号 (1-indexed)
    limit=0,   # 最大行数 (0 = 无限制)
)
if result.success:
    print(result.content)
else:
    print(result.error)

# 写入文件
result = safe_write_file(
    filepath="/path/to/file.txt",
    content="content",
    workspace_root="/path/to/workspace",
    max_bytes=10*1024*1024,
    mkdir=True,
)

# 删除文件
success, error = safe_delete_file(
    filepath="/path/to/file.txt",
    workspace_root="/path/to/workspace",
)
```

### 简化 API (向后兼容)

```python
from utils.safe_file_ops import read_file, write_file

content = read_file("/path/to/file.txt", workspace_root)
success = write_file("/path/to/file.txt", "content", workspace_root)
```
