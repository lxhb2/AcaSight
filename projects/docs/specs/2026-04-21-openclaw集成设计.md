# OpenClaw 集成与项目重构设计方案

## 1. 项目现状分析

### 1.1 当前架构

```
┌─────────────────────────────────────────────────────┐
│                    Chainlit UI                     │
└─────────────────────┬───────────────────────────────┘
                      │
┌─────────────────────────────────────────────────────┐
│                    Agent (LangGraph)                │
└─────────────────────┬───────────────────────────────┘
                      │ calls tools
┌─────────────────────────────────────────────────────┐
│     agent_file_tools.py (工具注册表 + 执行器)       │
└─────────────────────┬───────────────────────────────┘
                      │ uses
┌─────────────────────────────────────────────────────┐
│     safe_file_ops.py (安全文件操作)                │
└─────────────────────────────────────────────────────┘
```

### 1.2 存在问题

1. **架构分散**：工具调用逻辑分散在多个模块
2. **维护成本高**：需要自行维护安全机制
3. **扩展性受限**：新增工具需要修改多个文件
4. **模型配置单一**：所有任务使用同一模型

## 2. 重构目标

### 2.1 核心目标

1. **工具调用集中化**：将所有工具调用任务统一转交给 OpenClaw 处理
2. **双模型配置**：
   - OpenClaw：配备成本最低且满足基本工具调用需求的专用模型
   - 思考大脑：配备具备强大复杂任务处理能力的高性能模型
3. **功能完整性**：全面梳理与补充开发剩余功能

### 2.2 预期效果

- **架构清晰**：职责分明，易于维护
- **性能优化**：模型各司其职，资源利用合理
- **功能完整**：覆盖所有必要的学习系统功能
- **安全性高**：利用 OpenClaw 的安全机制

## 3. 技术选型

### 3.1 OpenClaw 版本

- **版本**：最新稳定版 (v2026.4.9+)
- **安装方式**：Git 克隆 + 本地构建

### 3.2 模型配置

| 模块 | 模型类型 | 推荐模型 | 理由 |
|------|----------|----------|------|
| **OpenClaw** (工具执行) | 轻量级 | Llama 3 8B 或 Gemma 7B | 成本低，响应快，足够处理工具调用 |
| **思考大脑** (决策分析) | 高性能 | Llama 3 70B 或 GPT-4 | 处理复杂任务分析和决策 |

### 3.3 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Python | 3.10+ | 主开发语言 |
| OpenClaw | latest | 工具执行引擎 |
| LangGraph | latest | 思考大脑 Agent |
| Chainlit | latest | 用户界面 |
| SQLite | 3.40+ | 数据存储 |

### 4.1 整体架构

└─────────────────────┬───────────────────────────────┘
                      │ 发送工具调用请求

│                    OpenClaw Gateway               │
│  ┌─────────────────────────────────────────────┐    │

                      │ 执行具体工具
┌─────────────────────────────────────────────────────┐

│  ┌─────────────────────────────────────────────┐    │
│  │  • 文件操作技能 (file_operations)          │    │
│  │  • 项目管理技能 (project_management)        │    │
│  │  • 资源管理技能 (resource_management)       │    │

│  └─────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘
```

### 4.2 核心组件

#### 4.2.1 思考大脑 (Thinking Brain)

**职责**：
- 学习规划与分析
- 任务安排与优先级
- 学习策略制定
- 结果评估与反馈

**实现**：
- 基于 LangGraph 的 ReAct Agent
- 配备高性能模型
- 与 OpenClaw Gateway 通信

#### 4.2.2 OpenClaw Gateway

**职责**：
- 工具调用管理
- 安全验证
- 执行控制
- 结果处理

**实现**：
- OpenClaw 核心网关
- 提供 RESTful API 接口
- 管理技能执行

#### 4.2.3 OpenClaw Skills

**职责**：
- 具体工具的实现
- 安全执行
- 结果格式化

**实现**：
- 文件操作技能
- 项目管理技能
- 资源管理技能
- 学习进度技能

│   │   ├── client.py         # API 客户端
│   │   ├── tools.py          # 工具封装

│   ├── pulse_project_management/

│       └── main.py

└── main.py                  # 主入口
```

### 5.2 通信协议

#### 5.2.1 思考大脑 → OpenClaw

**请求格式**：
```json
{
  "tool_call": {
    "name": "file_write",
    "args": {
      "filepath": "projects/test.md",
      "content": "# Test"
    },
    "thought": "需要写入测试文件"
  }
}
```

#### 5.2.2 OpenClaw → 思考大脑

**响应格式**：
```json
{
  "tool_response": {
    "success": true,
    "result": "文件写入成功: projects/test.md (5 bytes)",
    "error": "",
    "metadata": {
      "execution_time": 0.123,
      "skill": "pulse_file_operations"
    }
  }
}
```

### 5.3 技能设计

#### 5.3.1 文件操作技能 (pulse_file_operations)

**功能**：
- `file_read`：安全读取文件
- `file_write`：安全写入文件
- `file_delete`：安全删除文件
- `file_list`：列出目录内容

**安全机制**：
- 路径边界检查
- 敏感路径黑名单
- 大小限制
- 符号链接检测

#### 5.3.2 项目管理技能 (pulse_project_management)

**功能**：
- `project_create`：创建学习项目
- `project_list`：列出所有项目
- `project_status`：获取项目状态
- `project_update`：更新项目信息

**数据结构**：
- 项目元数据（名称、目标、状态等）
- 模块信息
- 学习进度

#### 5.3.3 资源管理技能 (pulse_resource_management)

**功能**：
- `resource_add`：添加学习资源
- `resource_list`：列出资源
- `resource_search`：搜索资源
- `resource_update`：更新资源

**资源类型**：
- 文档
- 视频
- 代码
- 笔记

## 6. 实现步骤

### 6.1 阶段一：OpenClaw 集成

1. **安装 OpenClaw**
   - 克隆仓库：`git clone https://github.com/openclaw/openclaw.git`
   - 安装依赖：`npm install`
   - 构建：`npm run build`

2. **配置 OpenClaw**
   - 创建配置文件
   - 配置轻量级模型
   - 启动 Gateway

3. **创建 OpenClaw 客户端**
   - 实现 API 客户端
   - 封装工具调用
   - 处理响应解析

### 6.2 阶段二：思考大脑重构

1. **重构 Agent**
   - 分离思考逻辑
   - 配置高性能模型
   - 实现与 OpenClaw 的通信

2. **实现学习规划**
   - 学习目标分析
   - 任务分解
   - 进度跟踪

3. **实现结果分析**
   - 学习效果评估
   - 反馈生成
   - 策略调整

### 6.3 阶段三：技能开发

1. **文件操作技能**
   - 实现安全文件操作
   - 测试边界情况
   - 优化性能

2. **项目管理技能**
   - 实现项目生命周期管理
   - 支持复杂项目结构
   - 集成学习进度跟踪

3. **资源管理技能**
   - 实现资源分类
   - 支持资源搜索
   - 集成推荐系统

### 6.4 阶段四：功能完善

1. **UI 集成**
   - 优化 Chainlit 界面
   - 支持实时状态更新
   - 实现学习数据可视化

2. **功能测试**
   - 单元测试
   - 集成测试
   - 端到端测试

3. **性能优化**
   - 模型推理优化
   - API 调用优化
   - 存储访问优化

1. **架构清晰度**：职责分明，模块化设计

该方案不仅解决了当前系统的问题，还为未来的功能扩展和性能优化奠定了坚实基础。
