# 脉冲学习系统 - 工具调用可视化功能

## 功能说明

现在 Web UI 可以**实时显示工具调用状态**，让用户知道系统正在执行什么操作。

## 效果展示

当用户发送消息触发工具时，UI 会显示：

```
┌─────────────────────────────────────┐
│  用户: 创建项目 网络安全              │
├─────────────────────────────────────┤
│  🔧 正在执行工具...                  │
│                                     │
│  [AI 的回复内容...]                  │
└─────────────────────────────────────┘
```

## 支持的工具

| 触发词 | 执行的工具 | 说明 |
|--------|-----------|------|
| "创建项目 xxx" | `create_project()` | 创建新学习项目 |
| "列出项目" | `list_projects()` | 显示所有项目 |
| "项目状态" | `get_project_status()` | 查看当前项目进度 |
| "创建模块" | `create_module()` | 添加学习模块 |
| "完成挑战" | `complete_challenge()` | 标记挑战完成 |
| "徽章" | `badge_manager` | 查看徽章墙 |

## 技术实现

### 后端 (`web_ui.py`)

1. **`_check_and_execute_tool()`** - 检测用户消息中的工具调用意图
2. **在 `_do_llm_stream()` 中** - 先执行工具，再将结果加入 LLM 上下文
3. **SSE 流式响应** - 发送 `🔧 **执行工具**: xxx` 标记

### 前端 (JavaScript)

1. **检测工具标记** - 解析 SSE 流中的 `🔧 **执行工具**` 文本
2. **创建工具调用 UI** - 显示蓝色边框的工具调用区域
3. **实时更新** - 工具执行完成后继续显示 AI 回复

## 使用方法

1. 打开浏览器访问 `http://localhost:5050`
2. 输入触发词，例如："创建项目 Python学习"
3. 观察 UI 中显示的 "🔧 正在执行工具..."
4. 工具执行完成后，AI 会基于工具结果回复
