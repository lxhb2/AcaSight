📋 Sci-XRD 智能分析系统 - 使用说明
=======================================

🎯 系统简介
----------
Sci-XRD 是一个专业的X射线衍射分析系统，集成了智能分析、批量处理、AI推荐和专业图表生成功能。

🚀 快速启动
----------

### 方式1：双击启动（最简单）
1. 双击 `双击启动.bat` 文件
2. 系统自动检查环境并启动
3. 浏览器自动打开 http://localhost:8000

### 方式2：批处理启动
1. 双击 `启动Sci-XRD系统.bat`
2. 查看详细启动过程
3. 浏览器自动打开

### 方式3：PowerShell启动
1. 右键点击 `启动Sci-XRD系统.ps1`
2. 选择"使用PowerShell运行"
3. 查看彩色输出界面

### 方式4：Python启动器（无黑窗）
1. 双击 `Sci-XRD-Launcher.pyw`
2. 使用图形界面启动
3. 点击"启动系统"按钮

🖥️ 系统要求
----------
- 操作系统: Windows 7/8/10/11
- Python版本: 3.8 或更高
- 内存: 4GB (推荐8GB)
- 磁盘空间: 1GB 可用空间
- 网络: 需要网络连接（用于AI功能）

📦 首次运行
----------
1. 系统会自动检查Python环境
2. 自动安装必要依赖（FastAPI, Uvicorn等）
3. 首次安装可能需要几分钟时间
4. 后续启动无需再次安装

🌐 访问系统
----------
系统启动后，可以通过以下方式访问：

### 主界面
- http://localhost:8000
- http://127.0.0.1:8000

### 功能页面
- 分析界面: http://localhost:8000/analyzer
- 批量处理: http://localhost:8000/batch
- API文档: http://localhost:8000/docs
- 系统状态: http://localhost:8000/status

### 如果浏览器未自动打开
1. 打开任意浏览器（Chrome/Firefox/Edge）
2. 输入地址: http://localhost:8000
3. 按Enter键访问

🔧 主要功能
----------

### 1. 单文件分析
- 上传XRD数据文件（支持.txt, .csv, .dat等格式）
- 智能参数配置（AI推荐参数）
- 实时图表显示
- 物相匹配和鉴定
- 结果导出（多种格式）

### 2. 批量处理
- 批量上传多个XRD文件
- 并行处理，提高效率
- 进度跟踪和实时报告
- 批量导出结果
- 统计分析和汇总

### 3. AI辅助功能
- 智能参数推荐（基于数据特征）
- 物相分析建议
- 结果解释和说明
- 优化建议和改进方向

### 4. 专业图表
- 出版级图表质量
- 无中文乱码问题
- 黑色曲线，专业样式
- 多种导出格式（PNG, PDF, SVG）
- 支持高分辨率输出（600 DPI）

### 5. 多格式导出
- Origin项目文件 (.opju)
- Word分析报告 (.docx/.txt)
- Excel数据表格 (.xlsx)
- CSV格式数据 (.csv)
- JSON结构化数据 (.json)
- 文本报告 (.txt)

🛠️ 故障排除
----------

### 问题1: Python未找到
```
解决方案:
1. 下载安装Python 3.8+: https://www.python.org/downloads/
2. 安装时勾选"Add Python to PATH"
3. 重新启动系统
```

### 问题2: 依赖安装失败
```
解决方案:
1. 手动安装依赖:
   pip install fastapi uvicorn[standard] numpy scipy matplotlib pandas
2. 如果pip失败，尝试:
   python -m pip install --upgrade pip
3. 使用国内镜像:
   pip install -i https://pypi.tuna.tsinghua.edu.cn/simple fastapi uvicorn[standard]
```

### 问题3: 端口被占用
```
解决方案:
1. 停止其他占用8000端口的程序
2. 或修改启动端口:
   编辑 web_interface/config.py
   将 port: 8000 改为其他端口（如 8080）
3. 重启系统
```

### 问题4: 数据库文件不存在
```
解决方案:
1. 确保数据库文件存在:
   F:\桌面\pdf2_final_complete.db
2. 如果不存在，可以从备份恢复
3. 或使用系统的基础匹配功能
```

### 问题5: 浏览器未自动打开
```
解决方案:
1. 手动打开浏览器
2. 输入地址: http://localhost:8000
3. 或使用其他浏览器尝试
```
